## World Events

### Balloon Crates

Floating balloon crates spawn daily in a configured area.

#### How They Work

1. Balloons spawn at dawn (configurable) over the area an admin has set. Until an area is set,
   nothing spawns and nothing is announced
2. Optionally, one balloon is also measured out for **each online player** on the same wave, from
   that player's own height rather than from spawn. A player underground with no room above them
   simply doesn't get one
3. They float and bob in the air with particles
4. **Attack them** (melee or ranged) to pop!
5. Loot rains down when popped
6. Balloons despawn after **5 minutes** if not popped

#### Balloon Loot

| Item | Weight | Amount |
|------|--------|--------|
| Notch Coins | 6 | 10-45 |
| Nothing | 7 | - |
| Emeralds | 2 | 1-3 |
| Gold Ingots | 2 | 1-5 |

#### Admin Commands

| Command | Description |
|---------|-------------|
| `/balloon spawn` | Spawn balloon at your location |
| `/balloon spawn <x> <y> <z>` | Spawn at coordinates |
| `/balloon setArea <x> <y> <z> <radius>` | Set spawn area |
| `/balloon setYRange <min> <max>` | Set altitude range |
| `/balloon setCount <n>` | Balloons per day |
| `/balloon announce on/off` | Toggle spawn announcements |
| `/balloon perplayer <true/false>` | Also give every online player their own balloon on each wave |
| `/balloon playerarea <true/false>` | Restrict per-player balloons to the configured area |
| `/balloon playerheight <up> <spread>` | How far above a player theirs appears, and how wide it scatters |

### Golden Caches

Rare treasure blocks that generate in the world as it is explored.

#### Features

- **Glowing** block (light level 12)
- Contains **valuable loot**
- Generates **buried under an oak tree**, in roughly **one chunk in three thousand**, worked out from
  the world seed and the chunk's own coordinates. The same chunk always gives the same answer, so it
  cannot be re-rolled by unloading and coming back
- Only **one may be waiting unopened at a time** by default, so covering ground quickly is not a way
  to farm them. Open the one that exists before another can appear
- Both numbers are configurable

#### Golden Cache Loot

| Item | Rolls | Amount |
|------|-------|--------|
| Notch Coins | 2-3 | 64 each |
| Notch Coins (bonus) | 1-2 | 16-64 |
| Diamonds | 3 | 2-6 |
| Emeralds | 3 | 4-12 |
| Netherite Ingot | rare | 1-2 |
| Enchanted Golden Apple | rare | 1 |

#### Admin Commands

| Command | Description |
|---------|-------------|
| `/cache spawn <radius>` | Spawn near you within radius |
| `/cache spawn_at <x> <y> <z>` | Spawn at exact location |
| `/cache announce <true/false>` | Toggle announcements |

### Heart Crystals

The rarest thing in the mod. Eat one for a permanent extra heart, up to **two extra rows** (twenty
crystals, taking you from ten hearts to thirty).

Dying takes one back, down to none. It never touches the ten hearts you start with. A server that
would rather hand out permanent hearts turns that off once with `/hearts loseondeath false`.

`/hearts` tells you how many you have and whether this server takes one when you die.

| Where | Chance per open |
|---|---|
| Common Crate | 0.03% |
| Rare Crate | 0.09% |
| Epic Crate | 0.2% |
| Balloon | 0.1% |
| Golden Cache | 0.3% |

Admin NPCs can also sell them: their stock is any item stack, so one can go in a server shop.
