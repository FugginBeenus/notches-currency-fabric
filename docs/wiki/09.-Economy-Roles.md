## Economy Roles

An **economy role** turns an NPC into a service. Assign one in the NPC editor's **Role** tab, or with
`/npc setrole <role>` while looking at the NPC. Right-clicking the NPC then opens that service.

| Role | What it does |
| --- | --- |
| **Shop** | A player shop the owner stocks and sells from. See [Shops](04.-Shops). |
| **Banker** | Opens the ATM / Bank screen. |
| **Auctioneer** | Opens the [Auction House](05.-Auction-House). |
| **Mailbox** | Hands over auction winnings and returns held in your mailbox. |
| **Raffle** | Opens the raffle - buy tickets, see the pot, claim prizes. |
| **Bounty** | Opens the bounty board - take and turn in bounties. |
| **Dealer** | Opens the casino (slot machine). |
| **Enchanter** | Repair gear, buy specific enchantments, or extract an enchant to a book. |
| **Cosmetics** | Buy cosmetics for coins (datapack-driven; sells any mod's cosmetics). |
| **Greeter** | Talks only - pairs with the dialogue system. |

Most of these are described in more detail under [Money Sinks & Faucets](10.-Money-Sinks-and-Faucets).

### Admin Shops

Separate from player shops, **admin shops** sell/buy items at admin-set prices with optional dynamic
pricing (prices drift with supply and demand). Bind one to an NPC with `/npc setrole adminshop <shop>`.
See the [Admin](Admin) page for setup commands.

### Any Entity, via the API

Roles aren't limited to Notch NPCs - other mods (or admins) can bind a role to **any** entity by UUID
through `NotchNpcApi`. Admin-only roles are gated to server operators.
