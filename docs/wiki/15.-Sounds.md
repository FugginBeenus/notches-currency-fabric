## Sounds

Every NPC can have a voice, and five more sounds for the things that happen to it. Open an NPC, go
to **Talk**, and press **Sounds...**.

### The six slots

| Slot | When it plays |
| --- | --- |
| **Voice** | a short sound when it is spoken to, and on every line it says |
| **Ambient** | on a timer, while it just stands there |
| **Hurt** | when it takes a hit |
| **Death** | when it dies |
| **Step** | replaces its footsteps |
| **Angry** | when it lands a hit on something |

Each row has a box for a sound id and a **Pick** button that cycles through good ones. The box fills
in as you type: the rest of the name shows in grey, and **Tab** or the **right arrow** accepts it.
The line under the box is green when the sound is real and red when it is not. Save with a typo and
the server tells you in chat rather than saving nothing.

**Pitch** shifts every sound on the NPC at once. Low for big and slow, high for small and quick.
That is how you get a whole cast out of one villager sound.

### Ambient sounds on a timer

**Ambient every** sets the gap. **Exact** plays on the dot, which is right for a blacksmith
hammering an anvil. **Random** varies the gap by up to half, which is right for chatter and
background noise.

An Exact ambient sound and an Exact timed animation set to the same gap land on the same tick, every
time. Set the anvil sound and the swing to 3 seconds and the clang arrives with the hammer. See
[Animations](14.-Animations) for the timed animation side.

### Your own sounds

Press **Custom...** on the Sounds screen.

1. Press **Open folder** and drop `.ogg` files in.
2. Type a short name and press **Import**.
3. The sound is now `notchcurrency:yourname`, and it shows up in the autofill like any other.

Click a row in that list to drop its name straight into whichever sound slot you had selected.

Rules: `.ogg` only, under 1 MB, up to 64 sounds. The file header is checked, so a renamed `.mp3` is
refused with a plain message.

**On a server**, an operator's import goes to the server on the spot and is kept in the world folder.
Every other player gets it automatically the next time they join. Nothing is pushed to players who
are already online, on purpose, so a bad upload cannot be used to grief a full server.

### Sounds from other packs

You can type any sound id, including one from a resource pack you made yourself. The server refuses
a `minecraft:` name that does not exist, because that is nearly always a typo. A name from any other
pack is accepted with a yellow note that it only plays for players who have that pack.

### Where the files live

Your own sounds sit in `config/notchcurrency/npc_sounds/`, with an `_import` folder inside it. The
game builds a resource pack called **NotchCurrencyAssets** from them and switches it on by itself.
Do not edit that pack by hand, it is rebuilt every time the folder changes.
