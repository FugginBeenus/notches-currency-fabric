## Currency Creator

Rebrand the coin for your server. Give it a **custom name** and **custom art**, and Notch Currency
applies it *everywhere* - the item, the balance HUD, the chat symbol, and every message and GUI that
mentions money. On a multiplayer server the coin is even **pushed to every player automatically**, so
there's no resource pack to hand out.

This is one of the mod's headline features: your economy can use *Rubies*, *Credits*, *Gil*, *Dubloons*
- whatever fits your server, with matching artwork.

---

### Renaming the coin

Set the coin's name and the new name flows into the item, the HUD, the chat glyph, and every
in-game message and screen (`You won 50 Rubies!`, `Ticket price: 100 Rubies`, and so on).

- **In-game:** `ModMenu → Notch Currency → Currency → Coin name`
- **Config file:** set `currency.itemName` in `config/notchcurrency.json`

> **Tip:** pick a name that reads well after a number ("Rubies", "Gold Dubloons"), since it's used in
> amounts. Leave it blank to keep the default "Notch Coin" / "coins".

---

### Custom coin art

Drop your artwork into the currency folder and it reskins the coin everywhere at once:

| File | Location | Purpose |
| --- | --- | --- |
| `coin.png` | `config/notchcurrency/currency/` | The coin - item, HUD icon, and chat symbol all use it |
| `coin_tails.png` *(optional)* | `config/notchcurrency/currency/` | The tails side, shown on the Coin Flip table |

A `README.txt` is placed in that folder the first time the game runs, explaining the same thing.

> **Art tips:** use a **16×16 PNG with a transparent background**. One texture is enough - because the
> item, HUD sprite, and chat glyph all point at the same file, a single PNG rebrands the whole economy.

---

### How it's applied (the resource pack)

Notch Currency turns your name + art into a resource pack automatically - you never build one by hand.

1. On game start (and whenever you save the config), the mod generates a pack called
   **`NotchCurrencyCustom`** in your `resourcepacks` folder.
2. It switches the pack on for you and reloads, so the new name shows up as soon as you press Save.
   If the game refuses to switch it on, you get a one-time chat reminder to do it in
   **Options → Resource Packs**.
3. Clearing the name and removing the art deletes the pack and switches it back off.

This also solves the tricky part - the coin **symbol in chat** (`⛁`) is a font glyph that points at the
same coin texture, so it reskins along with everything else.

---

### Server distribution (multiplayer)

On a dedicated server you set the coin **once** and every player sees it - no asking people to install
anything.

1. Put your `coin.png` (and optional `coin_tails.png`) in the **server's**
   `config/notchcurrency/currency/` folder.
2. Set the coin name in the **server's** `config/notchcurrency.json`.
3. When a player joins, the server sends them the coin art + name. The client writes it into a separate
   **`NotchCurrencyServer`** pack and enables it automatically.

Players can still keep their own personal `NotchCurrencyCustom` pack as well - the server pack is kept
separate so the two don't clash. Identical re-joins are skipped, and removing the server's art reverts
players on their next join.

---

### Summary

| Want to… | Do this |
| --- | --- |
| Rename the coin | ModMenu → Currency → Coin name (or `currency.itemName` in the config) |
| Reskin the coin | Drop `coin.png` in `config/notchcurrency/currency/` |
| Reskin the tails side | Add `coin_tails.png` in the same folder |
| Roll it out to a server | Put the files + name on the **server**; players get it on join |
