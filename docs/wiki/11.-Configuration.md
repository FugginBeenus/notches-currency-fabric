## Configuration

Almost everything is configurable. There are three layers: the in-game **config GUI**, the config
**file**, and **datapacks** for content catalogs.

### Config GUI (ModMenu)

With **ModMenu** installed, open **ModMenu → Notch Currency** for a settings screen with a search
box and sections. No other config mod is needed. Sections include:

- **Economy** - auction listing fee (flat / percent / max) and sale tax (% / max).
- **Wealth Tax**, **Savings Interest**, **Shop Rent** - the passive sinks and faucets (thresholds,
  rates, intervals, caps, grace).
- **Raffle**, **Bounty Board**, **Crates**, **Loans**, **Gambling** - each feature's knobs.
- **Enchanter** - repair cost, enchant price multiplier, extract cost, treasure toggle.
- **Cosmetics** - enable the cosmetics shop.
- **Currency** - the coin name for the [custom currency](02.-Currency-System) pack, the starting
  balance for new players, and the `/pay` confirm threshold.
- **Waystone Fee** - enable + per-teleport and dimensional fees (needs the Waystones mod).
- **Audit Log** - file logging + optional Discord webhook.
- **Balloon Crates**, **Golden Cache** - world-event spawn settings.

> On multiplayer, the GUI edits the **client's** local config. Server admins should edit the server's
> config file (or use commands); some values apply on the next world load.

### Config File

The config lives at `config/notchcurrency.json`. Example sections:

```json
{
  "auctionListingFeeFlat": 0,
  "auctionListingFeePercent": 0,
  "auctionListingFeeMax": 0,
  "auctionSaleTaxPercent": 0,
  "auctionSaleTaxMax": 0
}
```

World-event settings (balloons, golden caches) also live here - see the [Admin](Admin) page.

### Datapacks

Some content is defined by datapacks so you can add to it without code, and reload with `/reload`:

| Path | Defines |
| --- | --- |
| `data/<ns>/crates/*.json` | Loot crate types |
| `data/<ns>/cosmetics/*.json` | Cosmetics shop offers |
| `data/<ns>/notch_bounties/objectives/*.json` + `.../rewards/*.json` | Bounty pools |

The mod ships working defaults/examples for each.

### Custom Currency Art

`config/notchcurrency/currency/coin.png` (and optional `coin_tails.png`) drive the custom-currency
resource pack - see [Currency System](02.-Currency-System).
