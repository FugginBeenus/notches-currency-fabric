## Configuration

Almost everything is configurable. There are three layers: the in-game **config GUI**, the config
**file**, and **datapacks** for content catalogs.

### Config GUI (ModMenu)

With **ModMenu** installed, open **ModMenu → Notch Currency** for a settings screen with a search
box and sections. No other config mod is needed. Sections include:

- **Economy** - auction listing fee (flat / percent / max) and sale tax (% / max).
- **Wealth Tax**, **Savings Interest**, **Shop Rent** - the passive sinks and faucets (thresholds,
  rates, intervals, caps, grace).
- **Raffle**, **Bounty Board**, **Crates**, **Loans**, **Gambling** - each feature's knobs.
- **Enchanter** - repair cost, enchant price multiplier, extract cost, treasure toggle.
- **Cosmetics** - enable the cosmetics shop.
- **Currency** - the coin name for the [custom currency](02.-Currency-System) pack, the starting
  balance for new players, and the `/pay` confirm threshold.
- **Waystone Fee** - enable + per-teleport and dimensional fees (needs the Waystones mod).
- **Audit Log** - file logging + optional Discord webhook.
- **Balloon Crates**, **Golden Cache** - world-event spawn settings.
- **Treasury** and **Factions** settings, covered on the [Admin](Admin) page.

> On multiplayer, the GUI edits the **client's** local config. Server admins should edit the server's
> config file (or use commands); some values apply on the next world load.

### Config File

The config lives at `config/notchcurrency.json`. Example sections:

```json
{
  "auctionListingFeeFlat": 0,
  "auctionListingFeePercent": 0,
  "auctionListingFeeMax": 0,
  "auctionSaleTaxPercent": 0,
  "auctionSaleTaxMax": 0
}
```

World-event settings (balloons, golden caches) also live here - see the [Admin](Admin) page.

### Datapacks

Some content comes from datapacks, so you can change it without code: bounties, loot crates and
cosmetics shop offers.

#### The example pack

The mod writes a ready-to-use datapack to `config/notchcurrency/examples/notchcurrency_examples/`.
It holds the mod's default files and a `pack.mcmeta` set up for your Minecraft version. It does
nothing where it is.

To use it:

1. Copy the whole `notchcurrency_examples` folder into your world's `datapacks` folder. On a server,
   that is usually `world/datapacks/`.
2. Edit the files inside `data/`.
3. Run `/reload`, or restart.

- A file with the same path as one of the mod's files **replaces** it. For example,
  `data/notchcurrency/notch_bounties/objectives/default.json` replaces the default bounty list. Make
  it `[]` to turn the defaults off.
- A file with a new name **adds** to the mod's list.
- The mod refills the example folder when it starts: a deleted file comes back, but files you
  changed are kept.
- If you move to another Minecraft version, copy the folder again, because `pack.mcmeta` changes.

| Path inside `data/<namespace>/` | Defines |
| --- | --- |
| `notch_bounties/objectives/*.json` | Bounty jobs |
| `notch_bounties/rewards/*.json` | Bounty rewards |
| `notch_bounties/decrees/*.json` | Decree items for `/bounty admin` |
| `crates/*.json` | Loot crate types |
| `cosmetics/*.json` | Cosmetics shop offers |

#### Bounty fields

Each bounty file is a list of entries.

**Objectives**

| Field | Meaning |
| --- | --- |
| `type` | `kill` or `fetch` |
| `target` | The mob to kill or the item to bring, like `minecraft:zombie` |
| `min`, `max` | How many. Each bounty picks a number in between. `max` is optional. |
| `rarity` | `common`, `uncommon`, `rare` or `epic`. Default `common`. |
| `weight` | How often it comes up compared to the others. Default `1`. |
| `category` | A group name, like `hunt` or `gather`. Default `general`. |

**Rewards**

| Field | Meaning |
| --- | --- |
| `type` | `coins` or `item` |
| `item` | The item, for `item` rewards |
| `min`, `max` | How many coins or items |
| `rarity` | Pays out on bounties of this rarity |
| `weight` | How often it comes up compared to the others |

**Decrees**

| Field | Meaning |
| --- | --- |
| `item` | An item that stands for a category |
| `category` | The category it turns on |

Put decree items in the decree slots of `/bounty admin`. The board then only posts bounties from
those categories.

### Custom Currency Art

`config/notchcurrency/currency/coin.png` (and optional `coin_tails.png`) drive the custom-currency
resource pack - see [Currency System](02.-Currency-System).
