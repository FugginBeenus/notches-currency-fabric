## NPCs

The Notch NPC is a single, deeply customizable NPC built on **GeckoLib**. One blank-slate item spawns
it; everything else is configured in an in-game editor. It replaces the old shopkeeper entirely.

### Spawning & Ownership

- Place the **Notch NPC** item (creative tab) to spawn an NPC. **You own it.**
- Only the owner (or a server op) can edit it. Everyone else just gets its role interaction (shop,
  bank, dialogue, etc.).
- **Sneak + right-click** as the owner to open the editor.

### The Editor (tabs)

- **Look** - pick the model (vanilla humanoid, a GeckoLib model if installed, or a disguise as any
  entity), choose a skin (preset, player name, or URL), and open **Appearance** for tint, fade,
  glow, invisibility, size and the hitbox. A live preview shows changes.
- **Moves** - set behavior: **Stationary**, **Wander** (near its home), **Follow** (its owner or a
  named player), **Patrol** (waypoints placed with a route tool), or **Guard** (attacks hostile mobs).
  Extras: *Avoid monsters* and *Watch players*. **Schedule** lives here too: send an NPC somewhere at
  a time of day and it walks its own way there, so a shopkeeper opens up in the morning and goes home
  at dusk.
- **Role** - give it an economy job (see [Economy Roles](09.-Economy-Roles)).
- **Talk** - build a branching **dialogue** tree with conditions and actions, including opening any
  economy screen. Choose window or chat style. **Sounds...** lives here too: a voice, ambient, hurt,
  death, step and angry sounds, plus your own (see [Sounds](15.-Sounds)).
- **Pose** - pick a pose preset, open the **pose editor** to set each body part by hand, or hand the
  NPC an **animation** to loop. **Now and then** plays a second animation on a timer, exact or
  random, so a blacksmith can swing every three seconds (see [Animations](14.-Animations)).
  **Idle** sets how it stands between all that: **Statue** is frozen, **Breathe** is the calm
  default, and **Lively** adds the model's random clips. For APP.ly that is a small flourish
  often, a doze only when nobody is within 8 blocks, and the battery swap rarely.
- **Manage** - rename, pick up, delete, open **Stats & Abilities**, equipment, **presets**, and the
  three library screens: **Quests**, **Animations** and **Particles** (see
  [Particles](16.-Particles)). Stats & Abilities also holds the **fly ceiling** for an NPC with
  gravity switched off.

### Bring Your Own Model

Model and animate something in Blockbench and put it in the game, with no JSON to write and no
resource pack to build by hand.

1. In Blockbench, **File → Export → GeckoLib Animated Model**
2. Put the exported files in the import folder. The **Import folder** button opens it for you
3. In the editor: **Look → Choose Model → Manage models → New model**
4. Pick the model, texture and animations from the lists, name it, press **Create**

Every field is a list of things that exist rather than a name you have to type correctly. The clip
list is read out of the animation file you just picked, and clips called `idle` and `walk` are found
on their own. If something is wrong it says so on the spot, including the one that otherwise costs
you an evening: *"This model expects a 64 by 64 texture, but that image is 128 by 128."*

**Manage models** lists what is installed with its author and clip count, and a Remove on each. An
NPC wearing a model you remove quietly falls back to the built-in one.

#### Sharing with a server

A model one person made can work for everybody, without anyone else installing anything.

An operator presses **Share** and the model goes to the server, which keeps it in the world folder,
so copying the world copies the models. Players get it the next time they join, and a player who
already has it downloads nothing.

Nothing is pushed at anyone mid-session: applying a model reloads resources, which is a visible
hitch, and that is not something one person's button press should do to everybody else. It waits for
a join, for `/npcmodels sync`, or for the player to click **Get it now** when they talk to an NPC
wearing a model they do not have.

Operators can see and clear what the server holds with `/npc models list` and `/npc models drop`.

### Reactions

**Manage → Reactions.** This is how an NPC responds to the world without needing a dialogue tree.

Pick a trigger, then add actions to it:

| Trigger | When it runs |
|---|---|
| **When talked to** | a player interacts, before dialogue or a shop opens |
| **When a player comes near** | someone walks into range; re-arms when they leave |
| **When hurt** | it takes a hit, even if it is protected from the damage |
| **When killed** | it dies. There may be no player involved, a fall counts |
| **When it kills** | it kills something |
| **When an NPC is near** | another NPC comes close. For chatter between NPCs |
| **When a quest is finished** | a player hands a quest in to it |

Actions include saying a line (with a sound), paying or charging coins, giving an item, healing,
giving an effect, teleporting, giving or taking in a quest, playing an animation, and running a
command. The ones that hand out value or run commands are admin only.

**Every action can carry a condition.** That is the part worth knowing. An action set to *Only if →
On quest* fires only while the player is mid-quest, so one NPC can greet a stranger, nudge someone
working on a job, and thank them afterwards, all from this one screen.

Where several lines are on the same trigger, one is picked at random each time, and only lines whose
condition passes go into the draw.

### Quests and animations

Two library screens live on the **Manage** tab. What you write there is shared across the whole
server, and any NPC can use it by name.

- **[Quests](13.-Quests)** - jobs an NPC hands out, with rewards, chains, and faction sharing.
- **[Animations](14.-Animations)** - build a loop of poses on a timeline and give it to any NPC.

### Stats & Abilities

A dedicated screen with sliders (max health, speed, health regen) and toggles: protected, silent,
glowing, nameplate, no gravity, opens doors, leashable, invisible, plus a day/night **visibility**
rule (an NPC can be hidden and non-interactive off-schedule).

### Pick Up & Presets

- **Pick Up** packs the NPC's entire configuration back into the item; place it again to respawn the
  fully-configured NPC elsewhere.
- **Presets** save an NPC's whole setup to a named file (`config/notchcurrency/npc_presets/`) that
  can be applied to any NPC in any world - build a cast once, reuse it anywhere.

### Commands

| Command | Description |
| --- | --- |
| `/npc spawn [preset]` | Spawn an NPC where you stand (optionally from a preset) - op |
| `/npc presets` | List saved presets - op |
| `/npc setrole <role>` | Give the looked-at entity an economy role - op |
| `/npc clearrole` | Remove a role - op |
| `/npc info` / `/npc debug` | Inspect the looked-at NPC - op |
| `/npcmodels sync` | Fetch any custom models this server has that you do not |
| `/npc models list` / `/npc models drop` | See or clear the models the server holds - op |

### For Modders

`NotchNpcApi` lets other mods spawn NPCs, apply presets, and register **custom roles** so a
right-click runs their own code while all the built-in NPC features keep working.
