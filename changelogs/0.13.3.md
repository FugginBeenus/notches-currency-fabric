## 0.13.3: Minecraft 26.3

Notch Currency now runs on Minecraft 26.3. This release also fixes APP.ly on 26.3 and a Bounty
Board layout bug.

### Minecraft 26.3

- **A new jar for 26.3**: `notchcurrency-0.13.3+26.3.jar`. Like the other versions, it needs Fabric
  API and GeckoLib.
- Keys and clicks work with the new keyboard and mouse system in 26.3.

### Fixes

- **APP.ly on 26.3**: his head no longer spins and his eyes no longer stretch each time his idle
  starts over. This came from a bug in GeckoLib 5.5.7.
- **APP.ly's head door** now opens all the way in his battery animation on 1.20.1 and 1.21.1, the
  same as on the other versions.
- **Bounty Board**: the rows of taken bounties no longer run into the page buttons when an admin
  lowers the bounty limit.
- A bounty limit above 5 in the config file now counts as 5, because the board shows 5 rows. Before,
  bounties past the fifth were hidden.

### For model makers

- On 26.3, give every animated part of a custom NPC model a keyframe at 0 seconds. The NPCs page on
  the wiki explains why.

Servers and players should update together.
