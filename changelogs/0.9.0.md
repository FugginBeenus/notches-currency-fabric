## 0.9.0: Five versions

Notch Currency now runs on 1.20.1, 1.21.1, 1.21.11, 26.1.2 and 26.2. Grab the jar that matches your
game. Every one is built from the same source, so they all have the same features, and a fix lands on
all five at once rather than being backported one at a time.

Nothing is version gated. If a feature is in the mod, it is in every jar.

### What moved under the hood
Three of these versions changed how Minecraft draws things, and rather than freeze the old ones the
whole mod was brought forward:

- **NPC rendering.** From 1.21.11 a renderer never sees the entity. It fills in a description of what
  to draw during one pass and draws from that later, so everything the NPC needs, its pose, its
  model, its skin, its floating sign, now has to survive that gap. It does.
- **Screens.** The way a screen paints itself and the way it draws text both changed, twice. Every
  screen in the mod was rebuilt against the new shape.
- **Blocks, items, recipes and models.** Registry keys, item model definitions, recipe format and
  resource pack format all moved. All updated, all still working on 1.20.1.

### Share codes cross versions
A share code made on any of the five reads correctly on any of the other four, including everything
the NPC is wearing.

Item stacks changed shape at 1.21, which quietly broke this in both directions: a code from a newer
game arrived on 1.20.1 with the NPC's gear simply gone, and a code from an older game arrived with
every stack reset to one of the item. Neither said anything was wrong. Enchantments split three ways
rather than two, and dye and armour trim each moved at their own version again.

Gear now travels in a form that does not care which version wrote it: the item, how many, its
damage, its name, its dye, its trim, and its enchantments by name. Codes made before this release
still read the way they always did, so nothing you have already shared stops working.

### Fixes
- NPC poses, model switching and disguises work on the newer versions. Previously an NPC would show
  its skin and nothing else: no waving, no sitting, no borrowed mob shape.
- The model picker shows every mob again, hostile ones included, and they face the camera instead of
  standing at an angle. Previews across the editor, the picker and the pose screen are the right size
  and no longer clipped.
- The GeckoLib model is selectable without an unrelated mod installed. It is this mod's own model and
  never needed the check.
- The second skin layer sits on the body properly rather than floating beside it.
- Nameplates stay put on NPCs using a custom or mob model, and a dialogue window puts the NPC's name
  in its title instead of clipping a nameplate at the top of the portrait.
- The balance HUD is back on the newer versions, coin and all.
- Text fields show what you type again on the coin flip table, the ATM, the slot machine and every
  other menu with a field in it.
- The floating text screen previews each line under the field, colour codes and all.
