## 0.5.0: Minecraft 1.21.1 support

The mod now runs on **Minecraft 1.20.1 and 1.21.1**, with the same features on both. Download the
file matching your Minecraft version. Future versions will be added to the same shared codebase.

### New
- **Trinkets integration** (optional): with the Trinkets mod installed, NPCs get eight accessory
  slots, hat, face, necklace, cape, back, belt, ring, shoes, right on the equipment screen.
  Contents persist with the NPC, including through pick-up and placement.
- **Waystone fees in the menu** (optional, with Waystones): every destination in the waystone
  selection screen shows its teleport fee, and cross-dimension trips show the dimensional fee -
  no more surprise charges.
- **NPC equipment screen rework**: the same layout as the shops, labeled gear slots in a recessed
  container, a live preview of the NPC that shows equipment the moment it lands in a slot, and
  hover hints on every empty slot.

### Changed
- The balance HUD steps aside while a long chat message would run underneath it (1.21).

### Known notes on 1.21
- NPC nameplates sit at the standard height and no longer follow the NPC's pose (Minecraft 1.21
  removed the hook that made that possible).
